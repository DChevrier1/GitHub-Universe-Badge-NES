# Falling

A falling-platform arcade game by Jesse Williams (tragicmuffin), distributed
under the MIT license in `LICENSE.txt`.

- Source: https://github.com/xram64/falling-nes
- Revision: `52dcb8a951200562e696dfc2aba5d4d14edd0078` (v1.1)
- Original ROM: `falling.nes` in that revision, unchanged in this package.
- Size: 40,976 bytes; mapper 0, 32 KiB PRG, 8 KiB CHR.
- SHA-256: `e22b947542c2d7e595bf84725b333be7af8189c5965b9c53e356a249c7d79943`

`PROVENANCE.json` records the direct author-hosted ROM, license, and README
URLs and their individual hashes. The author documents rebuilding with the
NESASM 3.1 assembler using `NESASM3 falling.asm`. No rebuild or game-data
modification was used for this package.

Start begins the game. The directional pad moves the character; use the game's
own title screen and prompts for additional controls.
